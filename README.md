# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

####  リモートリポジトリ：ネット上のGit保存場所<br>ローカルリポジトリ：PCの中のGit保存場所

## プッシュとマージの違いは何でしょうか？

####  プッシュ：ローカルリポジトリからリモートリポジトリに反映させること<br>マージ：同じリポジトリ内で変更履歴を反映させること

## コミットとプッシュの違い

####  コミット：セーブや保存のような認識<br>プッシュ：変更内容を反映させる
